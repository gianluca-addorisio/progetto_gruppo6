# FIA Earthquake Damage Predictor

Progetto finale del corso di *Fondamenti di Intelligenza Artificiale*.

## Obiettivo
L’obiettivo del progetto è predire il livello di danno agli edifici causato dal terremoto del Nepal del 2015, utilizzando i dati forniti dalla competizione DrivenData:

**Richter's Predictor: Modeling Earthquake Damage**

## Setup della competizione
- **Variabile target:** `damage_grade`
- **Classi:**  
  - 1 → danno basso  
  - 2 → danno medio  
  - 3 → danno elevato  
- **Metrica di valutazione:** micro-F1 score
